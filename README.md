# RAG Learner

I am learning Retrieval-Augmented Generation by building the system manually.

## Project goal

Build a basic RAG application that can:

1. Read my own documents.
2. Split documents into smaller chunks.
3. Convert chunks into embeddings.
4. Store and search the embeddings.
5. Retrieve relevant chunks for a question.
6. Send the retrieved context to Amazon Bedrock.
7. Generate an answer based on the retrieved context.

## Learning rule

I will understand and implement each stage myself before using frameworks such as LangChain or LlamaIndex.

## Planned first project

A question-answering application for AWS and RAG study notes.
